# Engagement Ready AI

An AI-powered manufacturing readiness dashboard that helps teams assess, track, and improve engagement readiness in real time. Built as a submission for the **IBM watsonx Challenge**.

## What It Does

Engagement Ready AI evaluates manufacturing engagement readiness against defined criteria and surfaces gaps, risks, and recommended next steps through an interactive dashboard — reducing the manual audit work typically done in spreadsheets and documents.

## Getting Started

```bash
# Clone the repo
git clone https://github.com/FareenaAkram/engagement-ready-ai.git
cd engagement-ready-ai

# Install dependencies
npm install

# Run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
