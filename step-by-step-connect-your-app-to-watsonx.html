Connect Your App to watsonx — Beginner Guide

No prior IBM Cloud experience needed. Follow these phases in order.

Variable in your app Where you get it Required?
WATSONX_API_KEY IBM Cloud → Manage → Access (IAM) → API keys Required
WATSONX_PROJECT_ID watsonx.ai → Your project → Manage tab Required
WATSONX_URL Already defaulted to us-south.ml.cloud.ibm.com — leave blank unless your account is in a different region Optional
WATSONX_MODEL_ID Already defaulted to ibm/granite-3-8b-instruct — leave blank unless you want a different model Optional
ORCHESTRATE_API_KEY watsonx Orchestrate → Settings → API keys Optional — skip for now

Good news: Your app already works with mock data. The steps below are only needed to connect it to real AI. You can do Phase 1 in about 15 minutes and get real AI responses immediately.
Phase 1

Get your IBM Cloud account & API key

1
Create a free IBM Cloud account
🌐 Website: cloud.ibm.com

Go to cloud.ibm.com and click Create an account. Use your email address. The free (Lite) tier is enough to run watsonx.ai.

Already have an account? Skip to step 2.
2
Create an API key
🌐 IBM Cloud → top-right menu → Manage → Access (IAM) → API keys
  1. Log in to cloud.ibm.com
  2. Click your name/avatar in the top-right → Manage
  3. In the left sidebar click Access (IAM)
  4. Click API keys in the left sidebar
  5. Click the blue Create button
  6. Give it any name, e.g. factory-ready-key, click Create
  7. Copy the key now — it is shown only once
⚠️ Save this key somewhere safe (e.g. Notepad). If you close the window without copying it, you must create a new one.

This value goes in your app as WATSONX_API_KEY.

Phase 2

Create a watsonx.ai project & get the Project ID

3
Open watsonx.ai
🌐 IBM Cloud → Catalog → search "watsonx.ai" → Launch
  1. While logged into cloud.ibm.com, click Catalog in the top nav
  2. Search for watsonx.ai and click the result
  3. Click Get started or Launch — this opens dataplatform.ibm.com
Shortcut: You can also go directly to dataplatform.ibm.com and sign in with the same IBM Cloud account.
4
Create a new Project
🌐 watsonx.ai (dataplatform.ibm.com) → Projects → New project
  1. On the watsonx.ai home page, click Projects in the left sidebar
  2. Click New project (top right)
  3. Choose Create an empty project
  4. Give it a name, e.g. Factory Ready AI
  5. Click Create
5
Copy the Project ID
🌐 watsonx.ai → Your project → Manage tab
  1. Open your new project
  2. Click the Manage tab (near the top)
  3. You will see Project ID — it looks like: a1b2c3d4-e5f6-7890-abcd-ef1234567890
  4. Copy it

This value goes in your app as WATSONX_PROJECT_ID.

Phase 3

Put the values into your app (the .env.local file)

6
Create the .env.local file
📁 Your computer → the root of the bob challenge folder

In the bob challenge folder (the same folder that has package.json), create a new file called exactly:

.env.local

Open it in any text editor (Notepad, VS Code, etc.) and paste this — replacing the placeholder values with the real ones you copied:

WATSONX_API_KEY=paste_your_api_key_here WATSONX_PROJECT_ID=paste_your_project_id_here
That's all you need for watsonx.ai to work. The URL and Model ID already have defaults set in the code.
File location c:\Users\FareenaAkram\Downloads\bob challenge\.env.local
7
Restart the app and test it
💻 Your terminal / VS Code terminal

Stop the running app (Ctrl+C in the terminal), then start it again:

npm run dev

Go to the Readiness Review page and submit a review. If the connection works, the Integration Status badge will change from mock to live.

Phase 4 — Optional

watsonx Orchestrate (for task routing to real people)

Skip this for now if you just want the AI analysis to work. Orchestrate is the part that routes tasks to maintenance / QA / supervisor inboxes. Your app already shows a simulated version of this without it.
8
Request access to watsonx Orchestrate
🌐 IBM Cloud Catalog → search "watsonx Orchestrate"

watsonx Orchestrate is a separate product from watsonx.ai. It requires provisioning a dedicated tenant (your own URL like https://your-company.orchestrate.ibm.com).

  1. In the IBM Cloud Catalog, search for watsonx Orchestrate
  2. Follow the provisioning steps — you may need a paid plan or a trial
  3. Once provisioned, IBM gives you a tenant URL and you create an API key inside Orchestrate
⚠️ Orchestrate is not included in the free Lite tier. You need either a trial or a paid plan.
9
Add Orchestrate values to .env.local
📁 Same .env.local file you created in step 6

Once you have your Orchestrate tenant, add these two lines to your .env.local file:

ORCHESTRATE_API_KEY=paste_orchestrate_api_key_here ORCHESTRATE_URL=https://your-tenant.orchestrate.ibm.com

Restart the app again after saving.
